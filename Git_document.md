# Git Commands Documentation

## 1. git init
Used to initialize a new Git repository.

## 2. git clone
Used to copy an existing repository.

## 3. git status
Shows current changes in the repository.

## 4. git add
Stages files before committing.

Example:
git add .

## 5. git commit
Saves changes permanently with a message.

Example:
git commit -m "Initial commit"

## 6. git push
Uploads local changes to GitHub.

Example:
git push origin main

## 7. git pull
Downloads latest changes from GitHub.

## 8. git branch
Creates and manages branches.

## 9. git checkout
Switches between branches.

## 10. git log
Shows commit history.
